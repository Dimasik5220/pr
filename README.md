#  Как подготовить видео
# 1. Python (если ещё не установлен)
Зайдите на сайт: https://www.python.org/downloads/
Скачайте версию 3.7 или новее
При установке обязательно поставьте галочку Add Python to PATH

# 2. Библиотеки
Откройте командную строку (нажмите Win + R, введите cmd, нажмите Enter) и выполните команду:

pip install opencv-python numpy

Если выдаёт ошибку, попробуйте:

python -m pip install opencv-python numpy

# Как подготовить видео
Создайте на диске D папку:
D:\optical_flow_project\video
Положите в эту папку любое видео(10-40 секнуд) в формате .avi, .mp4, .mov или .mkv

Как запустить программу
# Способ 1: через командную строку (рекомендуется)
Откройте командную строку
Перейдите в папку, где лежит ваш файл main.py:

cd C:\путь\к\папке\с\программой

Запустите программу:

python main.py

# Способ 2: через среду разработки (PyCharm, VS Code и т.д.)
Откройте файл main.py в редакторе
Нажмите кнопку Run (обычно зелёный треугольник)

# Что делать после запуска
Появится меню:

Выбери режим работы
 1. Lucas-Kanade (разреженный поток)
 2. Farneback (плотный поток, цвет)
 3. ABSDIFF (простая разница кадров)
 4. MOG2 + подсчёт уникальных объектов
 5. Сравнить скорость методов
 6. Запустить всё подряд
 0. Выйти

Твой выбор:
Введите цифру (1, 2, 3, 4, 5, 6 или 0) и нажмите Enter.

# Как управлять во время работы
Клавиша	Что делает
ESC	Выйти из текущего режима (вернуться в меню)
s	Сохранить скриншот текущего кадра (в папку с программой)
# Что вы увидите на экране
# Режим 1 (Lucas-Kanade)
Зелёные линии — траектория движения объекта

Красная точка — текущее положение

Жёлтая стрелка — куда движется

Белые цифры — номер объекта

# Режим 2 (Farneback)
Верхняя половина — исходное видео

Нижняя половина — цветная карта движения

Красный = движение вправо

Синий = движение влево

Зелёный = вверх/вниз

Яркость = скорость

# Режим 3 (ABSDIFF)
Три картинки друг под другом:

Оригинал
Маска движения (белое = движение)
Объекты с красными рамками
# Режим 4 (MOG2) — самый полезный
Зелёные рамки вокруг объектов
Жёлтые линии — траектории
Синие стрелки — направление
Цифры — ID объектов

# Что будет в консоли после завершения видео
После того как видео закончится (или вы нажмёте ESC), в консоли появится итог:

ИТОГОВАЯ СТАТИСТИКА ПО ВИДЕО:

  Всего уникальных объектов за видео: 15
  Максимальное количество одновременно: 3
  Всего обработано кадров: 300


# Частые ошибки и их решение
Ошибка	Что делать
Ошибка: в папке нет видео файлов	Положите видео в папку D:/optical_flow_project/video/
ModuleNotFoundError: No module named 'cv2'	Установите OpenCV: pip install opencv-python
ModuleNotFoundError: No module named 'numpy'	Установите NumPy: pip install numpy
Не могу открыть видео	Видео повреждено или неподдерживаемый формат. Попробуйте другой файл.

# Примерное время работы
Обработка 1 минуты видео (30 FPS) занимает 1–5 минут в зависимости от режима
Самый быстрый режим — 3 (ABSDIFF)
Самый медленный — 2 (Farneback)
